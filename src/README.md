Для работы с объектами класса Task используются две параллельные коллекции. Это позволяет совместить быстродействие поиска по ключу и удобство работы с упорядоченными списками.

#### Расположение коллекций в `src/repository/LocalRepository.java`
### Используемые коллекции

* **`Map<ID, T> itemsById` (`HashMap`) - Поиск и доступ по ID**
  * **Зачем:** Обеспечивает мгновенный доступ к задаче по её уникальному идентификатору за время O(1).
  * **Где используется:** Для получения, редактирования или удаления конкретной задачи по id без необходимости обходить всё хранилище.
* **`List<T> items` (`ArrayList`) - Последовательное хранение**
  * **Зачем:** Подходит для сохранения порядка добавления, сортировки (по приоритету, названию) и применения фильтраций (по тегам или статусу).
  * **Где используется:** Для отображения меню со списком всех задач, отсортированных выборок и статистики.
